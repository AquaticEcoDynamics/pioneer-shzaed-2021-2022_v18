Animations

This chapter shows the kinds of movie the toolkit produces — a quick way to see what the coupled model resolves — and how to make them.

The animation scripts live in analytics/animations/ and share a single engine, animlib.py. They serve a range of work (tracer transport, oxygen dynamics, nitrogen-budget diagnostics), so they sit in one shared place rather than inside any single analysis package.

The shared engine

animlib.py (formerly animate_oxy_diags.py) provides the reusable machinery: hgrid reading with the tri_to_elem element→triangle mapping; node- vs element-centred rendering; dry-cell masking (dryFlagNode / dryFlagElement); fill-value masking (AED’s 9.97e36 sentinel → NaN); multi-stack auto-discovery; the gliding time-series inset; and the FFmpeg writer. It is also runnable standalone as a configurable multi-panel animator.

The scripts

Script Animates
animlib.py configurable multi-panel (scribe vars + AED diagnostics)
animate_oxy.py single tracer (1–2 panel); legacy standalone
animate_O2fluxes.py OXY_oxy + O2 atmospheric / sediment fluxes
animate_Nfluxes.py 6-panel nitrogen sediment / atmospheric flux sheets
animate_Nrates.py 6-panel 3D nitrogen process rates
animate_STO2.py salinity + temperature + oxygen
animate_velocity.py depth velocity magnitude
animate_trc.py full-domain conservative tracers TRC_tr1/2/3
animate_trc_zoomed.py Pioneer-mouth TRC plume + transect overlay
upper_river_connectivity_animation.py upper-river wet/dry connectivity

Running

Most scripts share the same flags (--hgrid, --outputs-dir, --fps, --dpi, --xlim/--ylim, --ndays, --single-stack, --n-stacks, --layer):

python animate_Nfluxes.py --outputs-dir <run>/outputs --hgrid <run>/hgrid.gr3
python animlib.py --diag-vars OXY_sat NIT_nitrif --aed-cmb <run>/outputs/aed_data_cmb_1.nc

Two scripts depend on the budget packages and self-bootstrap their paths: animate_trc_zoomed.py uses the generic core framework and the Pioneer run_config (so it honours --run 002|003), and upper_river_connectivity_animation.py uses core.

Tip

Full-resolution .mp4 renders are git-ignored; only the small web versions used in this guide are committed under docs/quarto/assets/videos/.
